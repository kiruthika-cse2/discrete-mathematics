Performance Insight

A student performance classifier built on Rough Set Theory — it shows not just what it predicts, but where it's certain and where the data genuinely leaves it undecided.

Student data

Each row is a student described by four condition attributes plus an observed outcome. Edit any cell, add rows, and every panel below recalculates instantly.

Approximation regions

For each outcome, the lower approximation is students the data classifies with certainty; the boundary is students who share a profile with someone who turned out differently.

Attribute reduct

The minimal set of attributes that classifies students just as well as using all four — found by greedily adding whichever attribute raises the dependency degree most.

Classify a new student

Enter a profile using the reduct attributes. The result is flagged certain only when every matching student in the data had the same outcome.

Built as a Smart India Hackathon prototype — classical Rough Set Theory (Pawlak), implemented from scratch, no external ML libraries.
